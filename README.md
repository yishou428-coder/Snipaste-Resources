## 🎯 What is Snipaste?

**Snipaste** is a free, lightweight screenshot and annotation tool that revolutionizes how you capture and work with screenshots. Unlike basic screenshot tools, Snipaste introduces innovative features like floating paste windows that let you keep screenshots visible while working on other tasks.

**Key Stats:**
- ⭐ Used by millions worldwide
- 🚀 Lightweight (~30MB)
- 💰 Completely free for personal use
- 🖥️ Cross-platform (Windows, macOS, Linux)
- ⚡ Written in C++ for maximum performance

**Download:** [Snipaste Official Download](https://www.snipaste-download.com )

## 🚀 Getting Started

### Installation

1. Visit [Snipaste Download Page](https://www.snipaste-download.com )
2. Choose your platform (Windows, macOS, or Linux)
3. Download the installer or portable version
4. Run the executable (no installation required for portable version)
5. Snipaste will appear in your system tray

### First Steps

1. **Take a Screenshot:** Press `F1` to enter screenshot mode
2. **Paste as Window:** Press `F3` to paste screenshots as floating windows
3. **Explore Features:** Right-click the system tray icon for options

## ✨ Core Features

### 1. Smart Screenshot (F1)

- Automatically detects window and UI element boundaries
- Supports multiple monitors and high-DPI displays
- Real-time color preview while selecting
- Supports rectangular and freeform selection

**Use Case:** Quickly capture windows, dialogs, or specific UI elements without manual alignment.

### 2. Floating Paste (F3)

The signature feature of Snipaste. Paste any screenshot or clipboard content as a floating window.

**Capabilities:**
- Drag and reposition
- Resize with mouse wheel (Ctrl + scroll)
- Rotate by double-clicking
- Adjust transparency (Ctrl + scroll)
- Enable mouse passthrough
- Group multiple pastes

**Use Case:** Compare designs side-by-side, reference documentation while coding, follow tutorials, or create mood boards.

### 3. Built-in Annotation Tools

- **Shapes:** Rectangles, ellipses, lines, arrows
- **Drawing:** Freehand brush with adjustable size and color
- **Effects:** Blur, pixelate, Gaussian blur
- **Text:** Add text with custom fonts and colors
- **Undo/Redo:** Full support for all annotations

**Use Case:** Highlight important areas, add notes, or create instructional screenshots.

### 4. Color Picker

- Pixel-level accuracy
- Multiple output formats: HEX, RGB, HSL, CMYK
- Magnified preview for precision
- Copy color value instantly (C key)

**Use Case:** Extract colors from designs, match brand colors, or reference color values.

### 5. History & Management

- Automatic history of all screenshots
- Search and filter by date
- Organize screenshots into groups
- Batch operations

**Use Case:** Never lose a screenshot again. Quickly find and reuse past captures.

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `F1` | Start screenshot mode |
| `F3` | Paste screenshot as floating window |
| `C` | Copy color value (in screenshot mode) |
| `Ctrl + S` | Save screenshot to file |
| `Ctrl + C` | Copy screenshot to clipboard |
| `Ctrl + Z` | Undo annotation |
| `Ctrl + Y` | Redo annotation |
| `Ctrl + Scroll` | Resize/adjust floating window |
| `Double-click` | Rotate floating window |
